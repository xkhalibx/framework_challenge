# Paws & Clover Dog Rescue

## Additions

* 100% classless HTML5 structure with zero `class` attributes
* Sakura.css and `normalize.css` stylesheets
* `css/style.css` using element, attribute, and pseudo-class selectors with CSS custom properties
* Live theme switcher (`Vader`, `Dark`, `Earthly`, `Pink`, `Light`) with `localStorage` persistence
* Monthly Medical & Foster Fund `<figure>` and `<progress>` bar
* Adoptable dogs table inside a `<fieldset>` with size filter (`All Sizes`, `Small`, `Medium`, `Large`)
* Interactive dog bio `<dialog>` modal with `<dl>` / `<dt>` / `<dd>` foster notes and pre-fill adoption button
* How Adoption Works numbered list with `<kbd>` fee highlight
* Adoption Inquiry Form grouped with `<fieldset>` and `<legend>` elements plus submission confirmation message
* Frequently Asked Questions `<details>` / `<summary>` list
